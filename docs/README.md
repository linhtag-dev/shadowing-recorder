# Documentation

Shadowing Recorder documentation is divided by audience. The root
[README](../README.md) gives the current-build overview, essential usage, privacy
boundary, and supported commands.

## Use Shadowing Recorder

The [user documentation](users/README.md) covers the current pre-launch build:

- [Practice with a YouTube video](users/how-to-guides/practice-with-a-youtube-video.md)
  explains the complete learner workflow.
- [Recording, privacy, and browser behavior](users/reference/recording-privacy-and-browser-behavior.md)
  records current user-visible lifecycle, storage, diagnostics, and format
  behavior.

These repository documents do not replace the consent, public policy, or
attribution surfaces still required before public launch.

## Maintain Shadowing Recorder

The [maintainer documentation](maintainers/README.md) routes contributors to
requirements, implementation status, technical design, architecture decisions,
privacy rules, test procedures, historical evidence, and release operations.
